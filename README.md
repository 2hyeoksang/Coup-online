# 쿠(Coup) 온라인

보드게임 **쿠(Coup)**를 웹에서 친구들과 즐길 수 있는 온라인 멀티플레이어 게임입니다.
방장이 방을 만들면 방 코드가 생성되고, 친구들이 코드를 입력해 참가하는 방식입니다.

## 기술 스택

- **백엔드**: Node.js + Express
- **실시간 통신**: Socket.IO (WebSocket)
- **프론트엔드**: HTML + CSS + JavaScript (바닐라)

## 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 서버 실행
node server.js

# 3. 브라우저에서 접속
# http://localhost:3000
```

## 게임 방법

1. 닉네임을 입력하고 **방 만들기** 또는 방 코드로 **참가하기**
2. 방장이 **게임 시작** (2명 이상 필요)
3. 각자 카드 2장 + 코인 2개로 시작
4. 자기 차례에 행동 선택
5. 마지막까지 카드를 지킨 플레이어가 승리

## 구현된 기능

- [x] 방 생성 / 참가 (방 코드 방식, 최대 6명)
- [x] 카드 분배 및 게임 시작
- [x] 기본 행동 (수입, 해외 원조, 쿠데타)
- [x] 카드 제거 시 공개 처리
- [x] 턴 시스템 및 승리 판정
- [x] 게임 로그
- [ ] 역할 행동 (세금, 암살, 훔치기, 교환)
- [ ] 챌린지 / 블로킹 시스템

## 프로젝트 구조
coup-online/
├── server.js # 서버 시작, 이벤트 연결
├── index.html # 게임 화면 구조
├── style.css # 디자인
├── script.js # 브라우저 동작
├── game/
│ ├── deck.js # 덱 생성, 셔플
│ ├── state.js # 게임 상태, 턴 관리
│ ├── room.js # 방 생성, 참가, 퇴장
│ └── action.js # 행동 처리
└── images/ # 카드 이미지

## 역할 카드

| 역할 | 능력 |
|------|------|
| 공작 (Duke) | 세금으로 코인 3개, 해외 원조 차단 |
| 암살자 (Assassin) | 코인 3개로 암살 |
| 사령관 (Captain) | 코인 2개 훔치기, 훔치기 차단 |
| 외교관 (Ambassador) | 카드 교환, 훔치기 차단 |
| 귀부인 (Contessa) | 암살 차단 |
